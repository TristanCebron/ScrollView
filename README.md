# ScrollView – Android Application

## Description

ScrollView is a simple Android application developed using Java and XML in Android Studio.

The application displays an article about The Beatles. The screen contains a title and two columns. The left column displays a subtitle, while the right column contains the main article.

The ScrollView component allows users to scroll vertically through the text.

At the bottom of the screen, there is an **ADD COMMENT** button that displays a Toast message saying **"Comment submitted!"** when clicked.

## Features

- Vertical scrolling through long text
- Two-column text layout
- Simple and clean user interface
- Comment button with Toast notification
- Custom application icon

## Technologies Used

- Java
- XML
- Android Studio
- Android SDK

## Android Components

- **LinearLayout** – Organizes UI elements
- **TextView** – Displays text
- **ScrollView** – Enables vertical scrolling
- **Button** – Handles user interaction
- **Toast** – Displays short notifications

## Installation

1. Download or clone the repository.
2. Open the project in Android Studio.
3. Build the application.
4. Generate an APK using **Build → Generate App Bundles or APKs → Generate APKs**.
5. Install the APK on an Android device.
